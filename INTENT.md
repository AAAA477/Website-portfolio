# INTENT

> The "why" of this project. This file changes rarely. When a decision in
> [PLAN.md](PLAN.md) conflicts with this file, this file wins.

## The one-sentence intent

Build a beautiful personal portfolio website that proves Andrew Adrian Ansah can
build beautiful things on the frontend — and that leaves a visitor genuinely
knowing who he is.

## Who this is for

| Audience | What they came for | What they must leave with |
|---|---|---|
| Recruiters / hiring managers | "Can this person do the job?" | Skills, projects, CV, a way to contact — inside 30 seconds |
| Engineers reviewing the work | "Is the craft real?" | Clean markup, smooth motion, no layout jank, readable source |
| Peers / collaborators / friends | "Who is Andrew?" | Personality, story, what he cares about, where he's headed |
| Andrew himself | A place to point at | One canonical link that stays current |

## What "success" means

The site is working when:

1. **It looks designed, not templated.** A visitor's first reaction is to the
   craft, not to a recognizable free theme.
2. **The frontend skill is self-evident.** Motion, spacing, typography and
   responsiveness *are* the portfolio piece — the site itself is exhibit A.
3. **You learn a lot about me.** Not just a skills list: the path from Ghana to
   the University of Alberta, the interest in Python, apps and AI, what gets
   built on weekends, what's being learned right now.
4. **Nothing is a dead end.** Every project links somewhere real. Every button
   does something. No `href="#"`.
5. **It performs and it's accessible.** Fast on a phone on mobile data,
   keyboard navigable, readable by a screen reader, respects reduced motion.
6. **Contact actually works.** A message sent is a message received, with
   honest success and failure feedback.

## Principles

- **Show, don't claim.** "Good at CSS" is worthless next to a page that feels good to use.
- **Substance over decoration.** Motion serves attention and hierarchy. If an
  animation doesn't help the reader, it's noise — cut it.
- **Honest content.** Real projects, real links, real dates. No placeholder work.
- **Accessible by default.** An inaccessible portfolio is a frontend skill issue,
  not a nice-to-have.
- **Own the stack.** Hand-written HTML/CSS/JS, no heavy framework, no page
  builder. The source is part of the portfolio and gets read.
- **Always shippable.** `main` is deployable at every commit.

## Non-goals

- Not a blog engine, CMS, or backend product.
- Not a framework showcase — no React/Next rewrite unless the intent above demands it.
- Not a resume clone. The CV is a download; the site is the experience.
- No dark patterns, no fake testimonials, no invented metrics.
